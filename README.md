# 活俠傳修改 Mod

繁體中文 | [English](README.en.md)

## 安裝方法 Installation

> [!IMPORTANT]
> 本 Mod 只支援 **BepInEx 6**（Unity Mono 版，建議 `6.0.0-be.697`），**不支援 BepInEx 5**。
> 裝成 BepInEx 5 時 Mod 完全不會載入，`BepInEx/LogOutput.log` 會顯示 `0 plugins to load`。
> 判斷方式：`BepInEx/core` 裡有 `BepInEx.Unity.Mono.dll` 是 6，只有 `BepInEx.dll` 是 5。

> [!NOTE]
> 目前版本對應遊戲 **1.0.6001.0**（版本號在主標題畫面左下角）。舊版遊戲上「劇情中隨時存檔」與寫進回想的功能無法使用。

- 從 [Releases](https://github.com/KazeNoYumeX/legend-of-mortal-mod/releases/latest) 下載 `legend-of-mortal-mod.zip`，內含 BepInEx 6 be.697，且已設定好 `Type = Camera`
- 將 `legend-of-mortal-mod.zip` 解壓縮到遊戲目錄下，遇到同名檔案請選擇覆蓋（若已裝過 BepInEx 5，請先刪除遊戲目錄下的 `BepInEx/core`、`winhttp.dll`、`doorstop_config.ini`）
- 自行安裝 BepInEx 的話，請下載 [BepInEx 6 be.697（Unity Mono x64）](https://builds.bepinex.dev/projects/bepinex_be/697/BepInEx-Unity.Mono-win-x64-6.0.0-be.697%2B5362580.zip)，啟動一次遊戲後關閉，打開 `BepInEx/config/BepInEx.cfg`，把 `[Preloader.Entrypoint]` 底下的 `Type = Application` 改成 `Type = Camera`（不改的話選單不會出現）
- 可以和骰子大師等其他 BepInEx 6 的 Mod 一起使用

### 升級 Upgrade

- 從 v1.1.x 以後的版本升級：只要覆蓋 `BepInEx/plugins/LegendOfMortalMod/LegendOfMortalMod.dll`
- 還在用 v1.0.0 或第一次安裝：整包解壓縮到遊戲目錄覆蓋

## 疑難排解 Troubleshooting

- 按 `F3` 沒反應：確認裝的是 BepInEx 6，且 `BepInEx/config/BepInEx.cfg` 裡是 `Type = Camera`（v1.0.0 的壓縮檔是 `Application`，請改掉或重新下載最新版）
- `BepInEx/LogOutput.log` 沒有更新：完全結束 Steam 後重新開啟，再從 Steam 啟動遊戲

## 使用方法 Usage

遊戲中按 `F3` 開關選單。按鍵可以在 `BepInEx/config/LegendOfMortalMod.cfg` 的 `MenuToggleKey` 修改，選單大小則是 `UiScale`。

| 分頁 | 功能 |
|---|---|
| 基本 | 遊戲加速、行動點無限、跳過本旬、無限消費、無限鍛造/煉丹/修練點數/銀兩、戰鬥結算按鈕、戰鬥結果與事件、本段劇情旗標、骰子指定按鈕、劇情中隨時存檔、切換心上人 |
| 角色屬性 | 主角所有屬性：搜尋、設定、+1 / -1、鎖定 |
| 好感度 | 每個角色的好感度，操作同上；「全滿」／「歸零」會把搜尋結果裡的角色好感度設成 100／0；點備註的「已結識」／「未結識」可以切換，「全部結識」會把搜尋結果裡的角色都設成已結識 |
| 旗標 | 劇情旗標，操作同上 |
| 書籍 | 所有書籍與武功秘笈的持有數量，操作同上；「全持有」會把搜尋結果裡還沒有的書設成 1，「歸零」會設成 0，但會跳過已修練過的秘笈（存檔不會保存數量為 0 的書，修練進度會一起消失） |
| 貴重品 | 每個貴重品的持有數量，操作同上；「全持有」會把搜尋結果裡還沒有的貴重品設成 1。貴重品多半是劇情道具，一次全拿可能影響劇情走向 |
| 雜物 | 每個雜物的持有數量，操作同上；「全持有」會把搜尋結果裡還沒有的雜物設成 1 |
| 技能 | 主角每個技能的等級（0 為未習得），操作同上；備註標示是決鬥或戰役技能 |
| 講經堂 | 生死簿與汗青書的每一筆紀錄，「目前」是達成次數（0 為未解鎖），未解鎖的紀錄有「解鎖」按鈕；搜尋「生死簿」或「汗青書」只看其中一本，「全部解鎖」會解鎖搜尋結果裡還沒解鎖的紀錄。紀錄存在所有存檔共用的全域存檔，不影響目前存檔，也無法用選單鎖回去 |

基本頁的選項：

| 選項 | 說明 |
|---|---|
| 遊戲加速 | 依欄位裡的倍率加速遊戲（預設 2 倍） |
| 行動點無限 | 打開時補滿行動點，之後做什麼都不扣點，直到關閉 |
| 跳過本旬 | 只能在大地圖用，3 秒內再按一次才執行。放棄本旬剩下的行動點直接換旬；途中有劇情該觸發（例如主線要求剩 2 或 1 點時）會停在那裡播劇情 |
| 無限消費 | 修練、煉丹、鍛造面板的「最大消費」次數不限，顯示為 ∞。面板開著時勾選也會馬上生效；取消勾選要等下次打開面板 |
| 無限鍛造/煉丹/修練點數/銀兩 | 勾選時把銀兩和點數設成最大值，之後花銀兩（商店、鍛造、劇情都一樣）和修練、煉丹、鍛造都不扣。還沒打開過的面板，點數在第一次打開時補滿。角色屬性頁鎖定的銀兩或點數以鎖定的值為準，要先解鎖 |
| 以下全部開啟 | 一次勾選或取消下面五個選項（選單最小化時這五個會隱藏） |
| 顯示戰鬥判定按鈕 | 戰鬥畫面上方顯示「判定勝利／落敗」（有平手出口的單挑還有「判定平手」），3 秒內再按一次才結算，劇情接續和真的打完一樣。單挑隨時顯示，團體戰只在暫停選單顯示 |
| 顯示戰鬥結果與事件 | 戰鬥中在基本頁下方用小字列出：勝利、落敗會把哪個旗標設成多少，以及關卡裡會觸發的事件和效果（對話、改數值、援手、切換劇情、結束戰鬥等）。單挑顯示目前回合，事件依回合、血量、狀態等條件；團體戰顯示經過秒數與雙方人數，事件依秒數、剩餘人數和條件，觸發過的標「已觸發」 |
| 顯示本段劇情旗標（判定寫進回想） | 劇情中在基本頁下方用小字列出這段劇情會設定的旗標（附目前的值），以及每個分支判定的條件，依目前的值標 ✔ 成立／✘ 不成立。遊戲實際做判定時，也會把各分支的結果（沒算到的分支標「—」）和走了哪一支寫進遊戲的「回想」，用金色小字顯示；這些紀錄不寫入存檔，讀檔後清除 |
| 骰子畫面顯示指定按鈕 | 劇情擲骰（檢定）的每個選項左邊多一顆「指定」，按下就直接擲出那個結果，不播轉盤。擲完後要重擲的話，和遊戲的重擲一樣會扣命運點 |
| 劇情中隨時存檔 | 劇情中（例如選項前）也能用選單的「存檔」。讀檔會從這段劇情的開頭重播，數值和這段劇情開始時一樣，看完一小段就回到同一個選項；背景、音樂和環境音也會補回存檔時的樣子。遊戲自己的存檔點、地圖和戰鬥照舊。設定會記住。**會寫入存檔，使用前請先備份存檔** |
| 選單不透明 | 點選單時不會點到後面的遊戲按鈕（預設開啟，會記住設定）。只擋點擊，選單外觀不變 |
| 選單最小化 | 隱藏其他分頁，視窗縮到只剩基本頁常用的功能（以下全部開啟那五個選項和選單不透明不顯示，但已打開的照樣生效）；戰鬥結果與事件、本段劇情旗標仍會顯示在下方。取消勾選就還原 |
| 切換心上人 | 下拉選單顯示目前的愛人，展開後點一個角色就切換（同角色屬性頁的「愛人」）。角色屬性頁鎖定了「愛人」的話會被改回去，要先解鎖 |

- 每個分頁都有搜尋，可以用名稱或備註來找
- 講經堂以外的每一列後面都有「鎖定」，鎖住後數值會一直維持（例如銀兩、毒藥點數）。對已鎖定的數值按設定（包含「全滿」／「歸零」）會改成鎖在新數值

> [!WARNING]
> - 旗標是劇情判斷用的，鎖定可能讓劇情卡住，不確定的話建議別鎖
> - 正常遊玩中技能沒辦法一次學很多，有些技能還是「上位取代下位」，直接改等級可能會同時擁有兩個，戰鬥中可能出問題
> - 改結識狀態只會讓角色出現在名單裡，不會補上相遇的劇情與旗標，可能讓相關事件錯亂或提前出現
> - 旗標、技能等分頁刻意沒有「全持有」／「歸零」這類一鍵按鈕，因為對存檔的風險比較高。修改前請多存檔

各版本的變更見 [CHANGELOG.md](CHANGELOG.md)。
